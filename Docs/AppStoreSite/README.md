# Сайт Pet Island

Готовый статический сайт на русском и английском: знакомство с приложением, поддержка и политика конфиденциальности. Работает без JavaScript, сборщика, cookies, внешних шрифтов и аналитики. Скриншоты показывают текущий интерфейс приложения; рисунки питомцев не менялись.

**Статус:** опубликован на [GitHub Pages](https://bortongo.github.io/pet-island-support/) 17 октября 2026 года. Репозиторий сайта: [BortonGo/pet-island-support](https://github.com/BortonGo/pet-island-support), ветка `main`, папка `/ (root)`; Enforce HTTPS включён. Приложение ещё не выпущено, поэтому кнопки загрузки нет.

## Проверить локально

Из корня проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory Docs/AppStoreSite
```

Открой `http://127.0.0.1:8765/`. Остановить сервер — `Ctrl+C`. Поддержка открывается по якорю `#support`, FAQ раскрываются без скриптов; переключатель языка ведёт на соответствующую страницу, включая политику.

## Обновить сайт

Сайт размещён в отдельном публичном репозитории; исходники iOS-приложения туда не входят.

1. Измени и проверь файлы в `Docs/AppStoreSite/` локально.
2. Скопируй в **корень [репозитория сайта](https://github.com/BortonGo/pet-island-support)** только `index.html`, `privacy.html`, `style.css`, каталоги `assets/` и `en/`, а также `.nojekyll`. Не загружай весь проект, `outputs/`, App Store metadata или этот README.
3. Закоммить и отправь изменения в `main` репозитория сайта. Pages уже настроен на **Deploy from a branch → main → / (root)**; повторная настройка не нужна.
4. Дождись успешного развёртывания в Actions или Settings → Pages. Открой обе главные страницы и обе политики без входа в GitHub; проверь картинки, язык, FAQ и email, в том числе на iPhone.

Держи прежние URL поддержки и политики рабочими. Коммит только в репозитории приложения сайт не обновляет. Настройка хостинга: [документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Какие адреса куда вставить

Готовые адреса для соответствующих локализаций App Store Connect:

| Поле | Русский | English (U.S.) |
| --- | --- | --- |
| Support URL | https://bortongo.github.io/pet-island-support/index.html#support | https://bortongo.github.io/pet-island-support/en/index.html#support |
| Marketing URL (необязательно) | https://bortongo.github.io/pet-island-support/index.html | https://bortongo.github.io/pet-island-support/en/index.html |
| Privacy Policy URL | https://bortongo.github.io/pet-island-support/privacy.html | https://bortongo.github.io/pet-island-support/en/privacy.html |

Ссылки ещё нужно внести в App Store Connect. В приложении **Настройки → Помощь и конфиденциальность** ссылка открывает опубликованную политику в браузере на языке приложения — русском или английском. Офлайн-текст и контактный адрес остаются доступны без сети. Apple требует ссылку и в консоли, и внутри приложения: [правило 5.1.1](https://developer.apple.com/app-store/review/guidelines/#data-collection-and-storage).

## Изображения и обновление

`assets/app-icon.png` — уменьшенная копия основной иконки из каталога приложения. `assets/{ru,en}-*.png` — уменьшенные до 660 px по ширине копии финальных снимков из `../AppStore/Screenshots/`. На сайт не подключаются файлы из исходников приложения: папка автономна.

Для магазина используй исходные PNG полного разрешения из [пакета App Store](../AppStore/README.md), а не уменьшенные изображения сайта. Временные сборки, генераторы HTML, контакты для ревью и служебные снимки не входят в публикуемую папку.
