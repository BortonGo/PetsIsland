# Подготовка Pet Island к выпуску — 17 октября 2026

Ветка: `codex/app-store-readiness`. База: `559b09b`.
Это отчёт о локальной подготовке, **не подтверждение готовности к публикации**.
Инструкция владельцу: [APP-STORE-LAUNCH.md](APP-STORE-LAUNCH.md).

## Что изменилось

- Взрослый лев и львица: отдельные фазы ходьбы и бега, стабильный масштаб и
  горизонт контакта. У бега различаются толчок, полёт, приземление и сбор лап.
  На переднем плане четыре фазы, в шрифтах DI/блокировки — два основных кадра.
  Полёт сохраняет просвет под лапами, его нельзя выравнивать как стоящую позу.
- Три наряда согласованы с новыми позами; обновлены соответствующие шрифты
  расширения и четыре беговых кадра каждой взрослой кошки в Pets Dash.
  Львенок, другие питомцы, их рисунки и время переключения кадров не менялись.
- «Настройки → Поддержать автора»: StoreKit 2, три добровольные разовые поддержки,
  цены из каталога Apple, без подписок и игровых преимуществ. Отмена, ошибка,
  ожидание подтверждения и недоступный каталог объясняются пользователю.
  Обработка транзакций продолжает работать после закрытия окна. Игровые
  сохранения, монеты и параметры питомцев не участвуют в оплате.
- «Помощь и конфиденциальность»: политика без подключения к сети, email
  `bortone52@yandex.ru`, отправка через почтовое приложение и копирование адреса.
  Добавлены русский и английский тексты в отдельном каталоге.
- «Язык приложения»: русский и английский через настройки языка отдельного
  приложения в iOS. Исправлены пропуски переводов счётчиков и запасов; каталоги
  проверяются автоматически, оба языка включены в приложение и расширение.
- Privacy manifest включён в оба targets; добавлено заявление о шифровании.
  У основной иконки удалён полностью непрозрачный alpha-канал без изменения
  цветовых пикселей. Альтернативные иконки сохранены.
- Подготовлены статические страницы поддержки и политики для отдельного сайта.
  Сайт, приложение и покупки не публиковались; настоящих платежей не было.

Первый прогон обнаружил устаревшие ожидания в двух тестах ресурсов: выбор индекса
из прежних восьми кадров и отсутствие учёта полёта львицы. Исправлены только эти
ожидания для взрослых львов, без ослабления проверки других питомцев.
В тесте максимального текста исправлена навигация к кнопке вне видимой области;
у контейнера убран избыточный accessibility identifier, чтобы не маскировать
идентификатор кнопки повторной загрузки. Кнопки связи и повторной загрузки
используют общие стили приложения: проверка снимков обнаружила слабый контраст
системной залитой кнопки на светлом фоне, и он исправлен.
Подпись после копирования email больше не наслаивается на прежний текст.
В тесте экспорта открытки убрана зависимость поиска кнопки от внутреннего
контроллера «Файлов»: повторно проверены отмена, открытие и сохранение PNG на iOS 27.
В языковом тесте исправлен тип accessibility-элемента: SwiftUI публикует
объединённую подпись как текст, а не обязательно как контейнер.
Изначальные неуспешные отчёты сохранены; итоговые — `regression-27-final.xcresult`
(390 модульных + 3 UI) и `language-ui-final.xcresult` (2 модульных + 9 UI).
Сводка всех 57 UI-сценариев: `ui-coverage-final.json` в папке отчётов.
Итоговый архив: `PetIsland-bilingual.xcarchive`, без подписи.

Отдельно сравнивались ресурсы с базой: остальные изображения питомцев и их нарядов
сохранены. Пересборка шрифтов проверяет неизменность 126 посторонних лиц в каждом
из двух базовых TTC. Изменения manifest ограничены 32 позами взрослого льва/львицы
на аксессуар. В `Localizable.xcstrings` дополнены 13 переводов, включая счётчики
шагов, находок, запасов и монет. Ранее существовавшие посторонние изменения
форматирования сохранены в рабочем файле; для коммита подготовлен отдельный
патч только с нужными переводами. Русский и английский явно объявлены в обоих
targets; выбор использует системную настройку языка приложения без подмены
`AppleLanguages`, изменения сохранений или перезапуска приложения из кода.

Отчёты, скриншоты, исходники генерации и архив находятся в игнорируемой папке
`outputs/app-store-readiness-20261017/`. Для сборки они не нужны.

## Что ещё блокирует выпуск

1. **Регистрация и оплата Apple Developer Program.** У владельца пока нет платного
   членства. Для проживания в России нужно подтвердить доступный путь у Apple;
   пополнение баланса Apple Account не является способом оплаты членства.
   Порядок и текст обращения находятся в инструкции. Отдельно проверяются
   договор на платные приложения, налоговые сведения и доступность выплат банку.
2. **Полная проверка оплаты.** Девять тестов контроллера проходят, но это не
   реальные транзакции StoreKit. Локальный сервер возвращал
   `SKServiceErrorDomain 2 / SKInternalErrorDomain 12` на iOS 27; на iOS 26.5 и 26.4.1 была
   также ошибка загрузки каталога. Причина не подтверждена. Известная проблема
   CLI-синхронизации конфигурации описана [Apple DTS](https://developer.apple.com/forums/thread/826971).
   Интеграционный тест сохранён, его ошибка не превращена в успешный результат.
   `check_project.sh` явно отделяет его флагом `PET_STOREKIT_TESTS=1`.
   До выпуска нужны успешная локальная покупка и Sandbox/TestFlight с настоящими
   product IDs; нельзя считать текущую реализацию проверенной платёжной системой.
3. **Публичные Support URL / Privacy Policy URL.** Страницы готовы, но пока доступны
   только как файлы. Нужно разместить их по HTTPS и вставить URL в App Store Connect.
4. **Устройство и совместимость.** Нужны iOS 17, настоящий iPhone, DI вместе с
   музыкой, Always-On, VoiceOver, восстановление старого сохранения и поведение
   оплаты при закрытии приложения. Симулятор не подтверждает расход батареи.
5. **Подпись и магазин.** Нужны подписанный архив, Validate App, TestFlight,
   настоящие скриншоты, возрастная анкета, App Privacy, DSA и отправка на ревью.
   Собранный локальный архив без подписи загрузить нельзя. App Review не пройден.

## Повторная проверка

```sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
PET_TEST_DESTINATION='platform=iOS Simulator,id=UUID_ОТДЕЛЬНОГО_СИМУЛЯТОРА' \
  bash Tools/check_project.sh
```

Для обязательной проверки локального StoreKit после настройки среды добавь
`PET_STOREKIT_TESTS=1`. В проекте есть схема `PetIslandTips` для локального каталога;
для Sandbox и архива выбирай обычную `PetIsland` без подмены магазина.

## Аккуратный коммит

Команды предназначены для текущей ветки `codex/app-store-readiness`, пока в индекс
не добавлены другие изменения. Список перечисляет конкретные проверенные файлы,
без архивов, снимков, промежуточной генерации и локальных отчётов. Полезный
`Tools/rebuild_lion_motion_fonts.py` оставлен: он пересобирает шрифты из уже готовых
ресурсов и проверяет сохранность остальных питомцев; генератор рисунков не нужен.

```sh
git branch --show-current
git diff --cached --stat
git apply --cached --check outputs/app-store-readiness-20261017/localization.patch
git add --pathspec-from-file=outputs/app-store-readiness-20261017/commit-files.txt
git apply --cached outputs/app-store-readiness-20261017/localization.patch
git diff --cached --check
git diff --cached --stat
git commit -m "Prepare release, improve lion motion and add bilingual support"
```

Если до `git add` индекс уже содержит чужие изменения или проверка патча не
проходит, остановись и проверь состав; не используй `git add .`. Рабочий
`Localizable.xcstrings` после этого может оставаться изменённым из-за старого
форматирования Xcode — в коммит попадут только 13 нужных переводов. Коммит и push
автоматически не выполнялись. Слияние в main лучше делать после проверки на iPhone.
