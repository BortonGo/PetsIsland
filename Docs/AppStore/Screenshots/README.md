## Происхождение и проверка

- Исходный код приложения: commit `c9f6149`, версия `1.0 (1)`.
- Сборка Debug из текущего проекта, Xcode 27.1, отдельные чистые симуляторы **iPhone 17 Pro Max и iPhone 17 Pro / iOS 26.5**. Использована локальная подпись симулятора для корректной работы App Group.
- Все изображения сняты командой `xcrun simctl io screenshot` в родном разрешении соответствующего симулятора, PNG RGB, без alpha. Оба размера предусмотрены [спецификацией Apple](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/), проверенной 17 октября 2026. Средний набор снят отдельно, а не уменьшен из большого.
- При сохранении удалён только полностью непрозрачный alpha-канал. Проверено равенство всех RGB-пикселей до и после перекодирования; размеры, цвета, питомцы и интерфейс не редактировались. Контрольные суммы файлов и пикселей находятся в `manifest.json`.
- Использованы существующие изолированные UI-фикстуры с сохранениями в памяти. Это настоящие экраны и ресурсы приложения, а не макеты. Данные демонстрационные: имена, дружба, монеты, запасы и прогулки. Русские имена питомцев в английских кадрах — пользовательские имена из фикстур, а не строки интерфейса.
- Нормальный размер текста. Вольер, карточка, прогулка и гардероб показаны в тёмной теме; игра — со своим обычным фоном. Для неподвижного кадра питомцев включён существующий режим уменьшения движения там, где его поддерживает фикстура.
- На большинстве кадров статус-бар симулятора показывает 09:41 и полный заряд. Для прогулок оставлено реальное время симулятора, чтобы оно согласовывалось со временем возвращения; оставшиеся минуты округляются приложением.
- Все двадцать кадров просмотрены после завершения переходов iOS: нет ошибок, диагностических надписей, незагруженных ресурсов и системных диалогов.
- Для снимков не использовались личный iPhone, сохранения пользователя или реальные покупки. Исходники приложения, рисунки и анимации не изменялись.

## Как повторить съёмку

Собери схему `PetIsland` в Debug для отдельных iPhone 17 Pro Max и iPhone 17 Pro. Не отключай подпись симулятора: App Group нужен настоящему экрану вольера. Установи сборку в соответствующий симулятор и запускай её со следующими аргументами:

| Экран | Аргументы фикстуры |
| --- | --- |
| Остров | `-home-clarity-preview -home-multiple` |
| Карточка | `-pet-profile-preview -profile-bond -profile-reduced-motion` |
| Прогулка | `-discovery-scene-preview -discovery-scene-shore -discovery-scene-dark -discovery-scene-reduced-motion` |
| Гардероб | `-pet-profile-preview -profile-route=wardrobe -profile-reduced-motion` |
| Аркада | `-arcade-preview`, затем в настоящем интерфейсе выбрать «Пузырьки» / Bubble Paws и «Поехали!» / Let's pop! |

К каждому запуску добавь `-AppleLanguages '(ru)' -AppleLocale ru_RU` либо `-AppleLanguages '(en)' -AppleLocale en_US`. Между вариантами заверши процесс приложения. Дождись окончания перехода и проверь экран, затем сними его через `simctl`. Удали непрозрачный alpha-канал при экспорте, сохранив RGB-пиксели и исходное разрешение. Повторная съёмка прогулок естественным образом изменит время возвращения. Поле Bubble Paws формируется случайно и при следующем запуске может отличаться; итоговые кадры показывают настоящие первые раунды игры.

## Перед загрузкой

Загружай файлы из нужного языкового каталога и для соответствующего размера в указанном порядке. В первую очередь заполни обязательный средний слот из `medium/`. Уменьшенные копии из `Docs/AppStoreSite/assets/` предназначены только для сайта. До публикации ещё раз сверь эти изображения с подписанной сборкой TestFlight: изменившиеся экраны нужно переснять. Отдельный кадр Live Activity/Dynamic Island лучше снять на физическом iPhone; в этот набор он намеренно не подменён макетом. Скриншоты покупок для App Review также готовятся отдельно после настройки реальных продуктов App Store Connect.
